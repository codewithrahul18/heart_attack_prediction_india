# ❤️ Heart Attack Prediction System using Machine Learning

## 📌 Introduction
Heart disease remains one of the leading causes of death worldwide. Early detection and risk assessment can significantly improve survival rates and healthcare outcomes.

This project presents a **Heart Attack Prediction System** built using **Machine Learning** techniques in Python. The system analyzes clinical and lifestyle parameters to predict the likelihood of a heart attack, demonstrating how data science can assist preventive healthcare.

---

## 🎯 Project Objectives
- Understand and analyze heart disease–related medical data
- Identify important risk factors contributing to heart attacks
- Build a reliable machine learning classification model
- Evaluate model performance using standard metrics
- Demonstrate a real-world healthcare AI application

---

## 🧠 Machine Learning Pipeline
1. **Data Loading**
   - Importing and inspecting the heart disease dataset

2. **Exploratory Data Analysis (EDA)**
   - Statistical summaries
   - Correlation analysis
   - Visual exploration of features

3. **Data Preprocessing**
   - Handling missing values
   - Feature scaling and normalization
   - Train-test data splitting

4. **Model Training**
   - Applying machine learning classification algorithms
   - Training the model on processed data

5. **Model Evaluation**
   - Accuracy score
   - Confusion matrix
   - Performance comparison

6. **Prediction**
   - Predicting heart attack risk for new input data
